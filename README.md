# Исследовательский анализ рынка недвижимости Санкт-Петербурга

Учебный проект по предобработке и исследовательскому анализу данных объявлений о продаже недвижимости.

## Задача
Подготовить данные к анализу и изучить факторы, связанные со стоимостью объектов недвижимости, а также отдельно исследовать рынок Санкт-Петербурга и его центральной части.

## Данные
Датасет содержит 23 699 объявлений о продаже недвижимости и характеристики объектов: цена, площадь, число комнат, этаж, высота потолков, расстояние до центра, парков и водоёмов, дата публикации и другие признаки.

## Что сделано
- проанализированы пропуски и выполнена предобработка данных;
- приведены типы данных и созданы новые признаки;
- рассчитана стоимость квадратного метра;
- выделены тип этажа и доли жилой/кухонной площади;
- проведён EDA для площади, цены, числа комнат, высоты потолков и срока экспозиции;
- обработаны выбросы по сроку публикации объявлений;
- сравнена средняя стоимость квадратного метра в наиболее представленных населённых пунктах;
- исследована зависимость стоимости квадратного метра от расстояния до центра Санкт-Петербурга;
- выделена центральная зона города и отдельно проанализированы её характеристики.
